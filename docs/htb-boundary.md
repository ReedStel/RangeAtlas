# Hack The Box boundary

RangeAtlas does not scan Hack The Box infrastructure, manage its VPN, retrieve targets, or publish
machine solutions.

If the project is used alongside personal HTB study:

- follow the platform rules and test only the exact provided target;
- keep VPN profiles and connection details outside the repository;
- do not publish flags, credentials, active-machine answers, or identifying target data;
- prefer general technique notes or authorised retired-machine material when platform rules allow;
- rebuild any public demonstration with RangeAtlas's synthetic fixtures.

The public repository should prove engineering ability without spoiling exercises or exposing
platform data.
